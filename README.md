# 🌿 EcoAventura: Guardianes del Bosque Esclerófilo

![Raulif Banner](https://images.unsplash.com/photo-1448375240586-dfd8f3793371?auto=format&fit=crop&q=80&w=1200&h=400)

> **¡Únete a Raulif en una aventura interactiva para proteger el corazón verde de Chile!**

**EcoAventura** es una aplicación web educativa y gamificada diseñada para conectar a las personas con la biodiversidad del bosque esclerófilo. A través de una interfaz inmersiva tipo "bitácora de explorador", los usuarios descubren flora y fauna nativa, desbloquean misiones y aprenden a ser verdaderos guardianes de la naturaleza.

## ✨ Características Principales

*   **🗺️ Mapa Interactivo "Bitácora"**: Un hermoso mapa ilustrado que se rellena con un sendero dorado a medida que progresas.
*   **🦊 Guía Virtual "Raulif"**: Un amigable zorro culpeo que te acompaña con consejos, audios y curiosidades.
*   **🏆 Sistema de Gamificación**: Desbloquea medallas, completa nodos de conocimiento y celebra tus logros con animaciones de confetti.
*   **📱 Diseño 100% Responsivo**: Disfruta de la experiencia en tu móvil con controles táctiles y vistas adaptadas, o en escritorio con todo el esplendor visual.
*   **🎨 Estética Premium**: Una interfaz limpia y luminosa (`Light & Fresh`) que evoca la serenidad del bosque.
*   **🔊 Experiencia Multimedia**: Narraciones de voz y efectos de sonido para una inmersión total.

## 🛠️ Tecnologías

Este proyecto ha sido construido con amor y código moderno:

*   **Core**: [React](https://reactjs.org/) + [TypeScript](https://www.typescriptlang.org/)
*   **Build Tool**: [Vite](https://vitejs.dev/)
*   **Estilos**: Vanilla CSS con variables CSS personalizadas (Sin dependencias pesadas).
*   **Animaciones**: CSS Transitions & Keyframes optimizados + Canvas Consfetti.
*   **Despliegue**: GitHub Pages (Automated Workflow).

## 🚀 Instalación y Uso Local

Si deseas correr este proyecto en tu máquina:

1.  **Clona el repositorio**:
    ```bash
    git clone https://github.com/DonGeeo87/Ecoaventura-Raulif.git
    cd Ecoaventura-Raulif
    ```

2.  **Instala las dependencias**:
    ```bash
    npm install
    ```

3.  **Inicia el servidor de desarrollo**:
    ```bash
    npm run dev
    ```

4.  ¡Abre tu navegador en la URL que indique la terminal (usualmente `http://localhost:5173`)!
